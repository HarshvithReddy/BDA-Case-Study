3. MAPREDUCE PROCESSING
=======================

---

## MAPPER

* Reads electricity readings from readings.csv.
* Reads sanctioned load information from zones.csv.
* Identifies the zone code for each reading.
* Calculates the load percentage for each reading.
* Emits:

  ```
    Zone Code  →  Load Percentage
  ```

---

## REDUCER

* Receives all load percentages for each zone.
* Finds the maximum load percentage for each zone.
* Emits:

  ```
    Zone Code  →  Maximum Load Percentage
  ```

5. HADOOP EXECUTION
===================

---

## STEP 1: COMPILE JAVA PROGRAMS

Command:

javac -cp "$(hadoop classpath)" MyMapper.java MyReducer.java Driver.java

---

## STEP 2: CREATE JAR FILE

Command:

jar -cvf zone-load.jar MyMapper.class MyReducer.class Driver.class

---

## STEP 3: CHECK HDFS INPUT FILES

Command:

hdfs dfs -ls /input/voltgrid

Input Files:

/input/voltgrid/readings.csv
/input/voltgrid/zones.csv

---

## STEP 4: REMOVE PREVIOUS OUTPUT

Command:

hdfs dfs -rm -r -f /output/problem2
